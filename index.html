Arquitectura y Gobernanza de Datos

Flujo de Datos BI

KAM Group

Arquitectura Cloud

Esquema de Extracción y Visualización

1. Odoo ERP

Origen transaccional. Expone datos estructurados vía módulo OpenAPI seguro[cite: 104, 105].

➔

2. Cloud Run & Scheduler

Script Python automatizado que consulta Odoo y orquesta la transferencia diaria a Google Cloud[cite: 104].

➔

3. BigQuery

Data Warehouse corporativo. Centraliza, limpia y almacena grandes volúmenes de datos históricos[cite: 105].

➔

4. Looker Studio

Capa de visualización. Consume datos procesados de BigQuery para alimentar tableros directivos[cite: 108].

Paso 1: Orquestación

Cloud Run

Servicio administrado de Google Cloud que aloja el script de extracción (Python)[cite: 102]. Se encarga de solicitar los datos a Odoo mediante autenticación segura e inyectarlos en BigQuery[cite: 102].

Paso 1.1: Gobernanza Financiera

Cloud Run: Costos Actuales

El esquema serverless garantiza un costo operativo mínimo, cobrando únicamente por los segundos de procesamiento que toma sincronizar los datos diarios hacia el almacén central[cite: 103].

Paso 2: Automatización

Cloud Scheduler

Funciona como el temporizador maestro (Cron Job)[cite: 104]. Dispara la ejecución del servicio de extracción en intervalos precisos (ej. diario a las 6:00 AM) sin necesidad de intervención manual[cite: 104].

Paso 3: Data Warehouse

Big Query: Almacenamiento

El repositorio central (OLAP)[cite: 105]. Almacena tablas estructuradas (ej. obt_ventas_pos, product_template) preparadas para análisis masivo y consultas ultrarrápidas desde las herramientas de visualización[cite: 105].

Capa Intermedia Opcional

Conexión Big Query - Sheets

BigQuery permite la extracción delegada hacia Google Sheets (Connected Sheets) para analistas que requieran manipular data cruda sin impactar el rendimiento de la base de datos principal[cite: 106].

Paso 4: Semántica Visual

Conexión Big Query - Looker

Looker Studio se enlaza directamente a BigQuery mapeando las métricas y dimensiones sin mover los datos subyacentes[cite: 107]. Aquí se configuran agregaciones predeterminadas y tipos de datos de forma segura[cite: 107].

Entrega Funcional

Informe Looker

El resultado directo para la gerencia[cite: 108]. Tableros interactivos que reflejan la realidad del negocio, conectando la extracción del ERP hasta la toma de decisiones estratégicas de manera fluida y escalable[cite: 108].

Consideraciones Finales de Entrega

  • Todo desarrollo de tablero nuevo incluye por definición 3 pantallas operativas integradas.
  • A partir de esta entrega oficial, se habilita una ventana de 7 días continuos para solicitar ajustes iterativos en función del feedback directo del usuario final.
  • El objetivo final es asegurar que la herramienta responda de forma precisa y ágil a la realidad de KAM Group.
